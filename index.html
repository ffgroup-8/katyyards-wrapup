03 · The tech stack

A one-page site built to say just enough.

The landing page introduces the district, tells the story, and keeps the rest behind a password until launch day. It is built with Astro and Sanity, hosted on Cloudflare, and every section is a reusable building block for the full site to come.

Astro

Fast on every device

Pages are server rendered with almost no JavaScript, so they load quick on phones, tablets and desktops.

Sanity CMS

Edit without a developer

Every section is a page-builder module the team can add, reorder and edit, with live preview that jumps from any text on the page straight to its field.

Password gate

Private until the reveal

Visitors enter a shared password once and stay signed in for two weeks, so partners can preview while the public waits.

SEO foundation

Ready to be found

Titles, descriptions, structured data, sitemap and robots rules are in place and checked on every deploy.

AEO baseline

Legible to AI

Structured answers, an llms.txt file and semantic content so AI assistants can read and recommend the district.

Accessibility

Built for everyone

Semantic HTML, keyboard navigation, contrast, screen reader support, and motion that switches off when a visitor asks for less of it.

Built to growEvery section is a reusable building block. When the full site is designed, the blocks carry over without being rebuilt.
Publish and it is livePublishing in the Studio triggers a rebuild, and changes reach the site in a few minutes.
Documented for the futureDocs in the repository cover modules, motion, visual editing and deployment, and typed content keeps the site and the Studio in lockstep.
Content in Sanity

One studio for the whole page.

Inside the studio
  • Page-builder modulesAdd, remove, reorder and repeat sections, each with its own thumbnail in the picker.
  • Live previewSee unpublished changes on the real site and click any text to jump to its field.
  • Background videoUpload video in the Studio for the pinned section, with an image fallback.
  • Anchors and linksPoint any link at any section, which powers the smooth-scrolling header nav.
04 · The design system

One master library powers everything.

Everything lives in one Master Library in Figma: colors, type, logos, components and layouts. Change a token once and it carries through every deck, document and design.
